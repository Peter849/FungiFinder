# FungiFinder
The goal of this project is to segment mushroom(s) on image(s) with the usage of the Watershed image processing algorithm

## Usage
### 1. Create and activate a virtual environment
### 2. Install the dependencies with the usage of the requirements.txt file
### 3. Run the program with the main.py file 
(*mandatory parameter is the relative path to the source image, that you would like to process*)
